### 导航规则
- **所有视图 1 次点击可达**：视图状态单一真相源仍是 `$store.core.view`，侧边导航项直接 `switchView`
- **统计胶囊 = 快捷筛选**：`store.openJobsWithFilter(preset)` 切到职位视图并预置筛选（收藏/已忽略/未打分/AI分/规则分/全部重置）；`jobsPanel` 监听 `gaj:jobs-filters` 事件合并筛选
- **跨视图链路**（沿用）：`store.openJob(jobId)` / `store.openCompany(brandId)` + window 事件 `gaj:open-job` / `gaj:open-company`

### 视图内结构
- 职位列表：搜索 + 筛选行（城市/状态/打分/收藏/忽略带标签，排序下拉分组 综合/薪资/时间/数据/其它）→ 列表 → 分页
- 职位详情：节导航（基础信息/市场参考*/规则打分/人工调分/AI打分/岗位描述/公司简介）+ 标题操作栏 + 滚动 sticky 摘要条（操作与标题栏一致，仅省供应商选择）
- 公司图鉴：两行工具栏（进度+想去+三榜 / 三模式+搜索+筛选）→ 卡片墙/象限图/对比；公司抽屉新增 **市场数据** 区块*
- 市场观察台：统一 `.tabs` 组件四 Tab（薪资定价/区域热力/信号雷达/技能热度）+ 下钻抽屉
- 规则配置 / 主简历：统一 `.tabs` 组件（含「关闭」返回职位列表）

## 二、样式变量与公共组件位置

| 文件 | 职责 |
|---|---|
| `gaj/web/static/styles/base.css` | **设计令牌唯一来源**：`--gaj-*` 全部颜色/字号/间距/圆角/阴影/焦点环。本次微调：`--gaj-foreground-3` #5C6573→#677288（对比度），新增 `--gaj-focus-ring` |
| `gaj/web/static/styles/components.css` | **新增公共组件层**：全局 `:focus-visible` 焦点环、`.tabs/.tab`（下划线式 Tab）、`.toolbar/.toolbar-row`（两行工具栏）、`.stat-card`（统计卡）、`.state-empty/.state-loading`（空态/加载态）、`.spin`（旋转图标动画） |
| `gaj/web/static/style.css` | 外壳：`.app-shell` / `.header` / `.sidebar`（分组导航）/ `.view-host` / `.log-panel` / `.toast` / 按钮三态 / `.stat-pill` 可点击变体 |
| `gaj/web/static/styles/<view>.css` | 各视图专属样式（沿用命名，未重构） |

**公共组件使用约定**：新增页面优先用 components.css 里的积木（tabs/toolbar/stat-card/state-empty），不要另写一套；改视觉先改 base.css 令牌，再改组件层，最后才是视图层。

## 四、后续叠加新功能的做法

1. **加导航项**：`index.html` 侧边栏对应分组内加 `<button class="sidebar-item">`，`@click="$store.core.switchView('xxx')"`；`store.js` 不需要改（视图路由是通用字符串）
2. **加视图岛**：按现有模式三件套——`views/xxx.html`（模板）+ `views/xxx.js`（`Alpine.data('xxxPanel')`）+ `styles/xxx.css`；挂载点插在 `index.html` 的 `view-host` 内（`data-tpl="xxx"`），loader 自动加载；CSS/JS 在 `index.html` 头部按序引用并把 `?v=` 版本号 +1（所有静态资源引用统一升版本号防缓存）
3. **加全局动作**：放顶栏 `.actions`；仅某视图可见的用 `x-show="$store.core.view === 'xxx'"`
4. **统计胶囊**：`index.html` 加 `<button class="stat-pill">`，`@click="$store.core.openJobsWithFilter({...})"`，preset 键名与 `jobsPanel.filters` 一致（search/city/status/scored/favorite/ignored/sort）
5. **改视觉**：令牌 → components.css → 视图 css，从上往下改，不要反向硬编码
