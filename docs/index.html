Agent Loop

一个自我进化的求职循环

坑位图鉴不仅是一个工具，而且是一个 Agent Loop。它持续采集、打分、分析、优化， 并反过来指导你调整预期——让每一次求职迭代都比上一次更精准。

每日循环
daily 命令一键编排
采集 BOSS直聘增量爬取
规则打分 4维 10项规则引擎
AI 分析 网页版大模型打分
简历优化 针对岗位定制简历
预期校准 数据驱动调整策略
策略迭代 更新画像与规则

为什么是 Loop？

求职不是一次性动作。你投的每个岗位、收到的每个反馈、面试的每轮对话， 都应该成为下一次决策的输入。坑位图鉴把这个回路做成了自动化：

1
采集：CDP 驱动 Chrome 增量浏览 BOSS直聘，模拟自然翻页节奏，连续 3 页全重复即判定已覆盖
2
打分：规则引擎四维十项即时打分，硬性淘汰看证据置信度，模糊区间触发 AI 介入
3
分析：网页版大模型（DeepSeek/豆包/通义/Kimi）深度分析，生成 0-10 分和面试建议
4
优化：针对目标岗位生成定制简历，把 JD 关键词融入你的真实经历
5
校准：打分数据反向指导你调整画像权重、薪资预期和硬性底线，形成持续优化
Core Capabilities

四大核心能力

从自动采集到深度分析，从简历优化到预期校准——每一环都可追溯、可配置、可自动化。

自动采集 BOSS直聘

Chrome CDP 调试模式驱动真实浏览器，增量浏览职位列表和详情。 自然访问节奏：连续整页重复时翻页间隔拉长，连续 3 页全重复即提前结束。 已抓职位自动跳过，采集覆盖率 ≥90% 时放慢基础节奏。

CDP 增量采集 自然节奏 覆盖率追踪

双层打分引擎

规则层：4 维度（财务/成长/资源/WLB）× 10 项评分，权重取自你的画像。 硬性淘汰 10 条规则，证据置信度 < 60% 只标 REVIEW 不误杀。 AI 层：规则标记需介入的岗位，自动调用网页版大模型深度分析。

4 维度 10 硬规则 置信度分级 10 AI 触发器

针对性简历优化 实验性

输入目标岗位 ID，AI 读取 JD 全文和你的主简历，生成针对性优化版本。 支持 optimize（微调）和 rewrite（重写）两种风格，把岗位关键词 融入你的真实经历，不造假不夸大。 该功能尚为实验性、有待测试优化，欢迎贡献改进。

JD 全文分析 optimize / rewrite 主简历管理

预期校准与反馈

打分数据反向指导你调整求职策略：哪个薪资段位的岗位通过率最高？ 哪些技术栈最稀缺？你的硬性底线是否太严或太松？ 画像权重可一键切换 5 套预设（平衡/成长/财务/生活/资源优先）。

Agent Interface

面向智能体的 JSON 接口

所有操作统一走 python3 -m gaj agent， stdout 只输出一个 JSON 信封。智能体可以直接 json.loads，按 ok / error.code 决策。

status 健康检查 + 数据概况（任何流程的第一步）
jobs 查询职位列表（筛选/排序/分页）
job 单职位详情（JD 全文 + 规则分 + AI 分）
analyze AI 打分（--job 单个 / --auto 批量）
crawl 增量采集（自动降速、覆盖提前结束）
daily 每日编排：采集 → 挑候选 → AI 分析 → 摘要

容错保障： 所有命令都有最外层异常兜底，任何情况下都会输出 JSON 信封并以退出码结束，不会静默挂起。 数据逐个职位增量落盘，超时 kill 后重跑不会重复抓取。
