## 四、现状 UI/UX 问题清单（分级）

### 结构性问题（影响承载能力）
1. **顶栏 13 元素过载**：品牌 + 6 统计胶囊 + 3 视图切换 + 4 全局操作挤在 52px 单行，1280px 下已逼近极限，功能继续增加必然崩坏
2. **导航与操作无分层**：视图切换、设置、简历、打分、批量全部平级混排，没有"去哪"与"干什么"的区分
3. **配置/简历用 toggle 语义**（再点返回职位列表），与 guide/observatory 的常驻视图语义不一致，心智模型混乱
4. **无规划中的功能落位**：TODO#3 行业观察无任何入口位置
5. **无工作台/首页概念**：打开应用直接进职位列表，统计胶囊不提供任何跳转

### 信息密度与层级问题（高频页面）
6. 职位列表项：收藏徽标 + 忽略按钮 + 规则分 + AI 徽标 + 技能标签平铺，关键信息（状态/优先级）无视觉锚点
7. 排序下拉 13 项无分组，筛选行 6 个下拉无标签，识别成本高
8. 职位详情操作栏双份（标题栏 + sticky 摘要条），且 AI 供应商选择出现在标题栏，职责混杂
9. 详情节导航占 148px 竖栏 + 未来左侧导航 = 双导航嵌套，小屏吃紧
10. 公司图鉴工具栏 8 控件单行；观察台无行业独立入口

### 一致性与细节问题
11. 面板容器不统一：`config-panel` / `guide-panel` / `main` / `observatory-panel` 各自为政
12. Tab 样式两套（config-tabs / obs-tabs / view-switch 三种变体）
13. 按钮无 `:focus-visible` 焦点环；`--gaj-foreground-3`（#5C6573）在小字号下对比度约 3.1:1，低于 4.5:1
14. **emoji 当图标**：AI 打分区 `🤖` 前缀、保存中 `⏳`；favicon 用 🎯 emoji
15. 详情节导航、sticky 摘要条等共享组件无统一规范文件，后续新增功能容易继续发散

## 五、新信息架构提案

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏: 品牌 坑位图鉴 │ 统计胶囊(可点击→直达筛选) │ 规则打分(primary) 批量 │

│ 侧边导航  │                                                    │
│ 工作台    │               视图内容区                           │
│  · 职位列表│  (各视图岛, 统一面板容器 + 统一工具栏)              │
│  · 公司图鉴│                                                    │
│ 市场  │                                                    │

│  · 行业观察 │ ← TODO#3 规划占位(禁用态+徽标)                    │
```

**要点**
- 主导航左侧化并分组（工作台/市场/配置），所有视图 1 次点击可达；新增功能按组自然落位，不再挤顶栏
- 顶栏只保留：品牌、可点击统计胶囊（职位/规则分/AI分/未打分/收藏/已忽略 → 跳职位列表并预置筛选）、规则打分（primary 常驻）、批量（职位上下文）
- 配置/简历从"按钮 toggle"改为导航项，语义统一为"当前视图"
- 高频操作固定入口：规则打分（顶栏常驻）、收藏/未打分（统计胶囊直达）、批量删除（职位列表工具栏常驻，不再依赖批量模式切换才能看到工具栏）
- TODO#1/#4 落地为职位详情「查看公司图鉴」按钮 + 「市场参考」区块；TODO#2 落地为公司抽屉「市场数据」区块；TODO#3 落位为导航占位 + 观察台行业入口；TODO#5 落位为规则配置「AI 规则矫正」恢复开关

## 六、视觉基础统一方案（保持原风格基调）

- **保留**：暗色基调、`--gaj-*` 令牌体系、Inter + 系统中文字体栈、蓝主色、8pt 间距网格、圆角尺度 —— 只做归一化，不换皮肤
- **新增**：`styles/components.css` 公共组件层 —— 按钮四态（默认/hover/focus-visible/disabled）、徽章、标签、统计卡、Tab、工具栏、表格、空态的统一规范，逐步替换各视图手写样式
- **令牌微调**：`--gaj-foreground-3` 提亮一档（小字号对比度 ≥ 3.5:1），新增 `--gaj-focus-ring` 焦点环令牌
- **图标规范**：清除 🤖/⏳ emoji 图标（换 Lucide），favicon 换 SVG 靶心图形
- **面板统一**：所有视图使用同一面板容器与工具栏组件；节导航在详情内保留但压缩宽度、缩小占用
