## 使用顺序建议

1. **填充自己的 `profile.md`** → 保存成配置文件，是产品的核心数据。
2. **每次看到新机会时，对照 `jd_fields.md` 把页面信息提取成结构化字典**。这一步可以先用人工，后续写一个简单的表单或浏览器插件自动抓。
3. **程序先跑“规则评估”**，得到基础四维分数和淘汰标记。
4. **检查 `ai_fallback.md` 中的触发条件**，决定是否调 AI，调完合并最终评分。
5. **把原始JD、结构化数据、规则分数、AI修正、最终总分和个人笔记全部存入数据库**，完成一次“机会图鉴”的记录。

有了这些模板，你后面的代码逻辑就非常清晰了：读画像→解析JD→规则打分→条件调用AI→存储。无论最后用 Python 脚本还是 FastAPI，都是对这些数据的流转处理。
